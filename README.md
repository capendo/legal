# capendo-legal

Static legal & support pages for the Capendo iOS app, served via GitHub Pages.

| Page | URL |
|---|---|
| Landing | `https://capendo.github.io/legal/` |
| Privacy Policy | `https://capendo.github.io/legal/privacy.html` |
| Support | `https://capendo.github.io/legal/support.html` |
| Terms & Subscriptions | `https://capendo.github.io/legal/terms.html` |
| Account & Data Deletion | `https://capendo.github.io/legal/account-deletion.html` |

Plain HTML, no build step. Edit the `.html` files and push to `main`.

Contact email used across pages: `dpw.vanderhoeven@gmail.com` — swap to a
branded address (e.g. `support@capendo.app`) once a domain is set up.
